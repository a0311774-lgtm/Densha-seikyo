# 電車聲響（網頁 App）

跟住 GPS 車速，即時合成汽油引擎聲同六前速波段。呢個係可以喺 iPhone Safari 開啟、再加入主畫面嘅 Progressive Web App，唔係 App Store 安裝檔，亦唔需要 Xcode。

iOS 唔允許直接下載一個檔就安裝未簽名嘅 App；用 Safari 加入主畫面，就係而家喺 iPhone 用到呢個產品最直接嘅方法。

## 喺 iPhone 上使用

1. **用 Safari 打開呢個網站**（盡量唔好用 WhatsApp、微信、Instagram 入面嘅內置瀏覽器，呢啲環境可能冇「加入主畫面」，定位同聲效都可能受限制）。
2. 當系統問位置權限，請允許。GPS 車速喺**戶外實際行駛**時先比較準；室內、隧道或者高樓之間訊號可能唔夠好。
3. 按紅色 **啟動**，會先有啟動馬達聲，然後怠速。之後就可以聽到跟車速同波段變化嘅引擎聲。
4. 喺 Safari 底欄按 **分享**，再揀 **加入主畫面**。以後喺主畫面開啟，會以獨立 App 畫面顯示，冇瀏覽器工具列。畫面可以離線再開；要用 GPS 車速時仍然需要定位。

室內想先試聲同換檔，請開啟 **示範模式**，用滑桿改車速。

呢個係網頁 App，唔係 App Store 安裝。加入主畫面之後，外觀同操作會接近原生 App，但安裝來源係你打開嘅這個網站。

## 點樣架設（靜態網站）

成個資料夾係靜態檔，唔需要編譯。用任何支援 HTTPS 嘅靜態託管都可以，例如 GitHub Pages、Netlify、Cloudflare Pages，或者自己嘅網頁伺服器。所有資源都用相對路徑。

本機預覽（電腦瀏覽器測試）：

```bash
cd /workspace/DenshaSeikyo-web
python3 -m http.server 8080
```

然後喺瀏覽器打開 `http://127.0.0.1:8080/`。

**iPhone 要用 GPS，網站必須以 HTTPS 提供**（本機 `localhost` 例外，但 iPhone 經區網 IP 用 HTTP 通常會被拒絕定位）。將呢個資料夾上傳到有 HTTPS 嘅主機，再用 Safari 打開個連結即可。

本 App 唔會追蹤、唔會做分析，除咗載入呢個網站自己嘅檔案之外唔會出外聯網路。

## 使用提示

- 按 **啟動** 之後先會出聲。iPhone 有時要喺你親手按掣嗰下先開到音訊，所以第一次請直接撳「啟動」。
- **音量**滑桿控制引擎聲大小。網頁音訊一般即使開咗側面靜音鍵都會出聲；唔想出聲就將音量拖去 0，或者按 **熄火**。
- 關閉示範模式，而且 GPS 已鎖定並有有效車速時，會改用路面 GPS 車速。定位被拒或者精確度不足時，畫面會清楚顯示狀態。
- 換檔大約 0.26 秒，轉速會短暫下跌，引擎聲會有一頓切斷。

## 系統要求

- iPhone 建議用 iOS 16 或更新嘅 Safari
- 直向為主
- 需要允許位置權限先可以用真實 GPS 車速
